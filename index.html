CPU Scheduling Visualizer

Interactive Demonstration of Scheduling Algorithms: FCFS, SJF, and Round Robin Algorithms

First Come First Serve (FCFS)

The simplest scheduling algorithm — processes are executed in the order they arrive.

About the Project

This project aims to visualize CPU scheduling algorithms used in operating systems. It demonstrates process handling by the scheduler through visual Gantt charts. The system supports FCFS, SJF, and Round Robin algorithms.

Objective

The objective is to provide an intuitive, visual and interactive understanding of CPU scheduling behavior. Users can enter process data and instantly see execution order, waiting times, and turnaround times.

Results & Insights

- FCFS: Simple and fair, but causes convoy effect.
- SJF: Optimizes waiting time but may starve long processes.
- Round Robin: Ensures fairness and responsiveness using time quantum.
Visualization helps to compare efficiency across various algorithms clearly.

Conclusion

The CPU Scheduling Visualizer transforms theory into interactive learning. It bridges the gap between algorithm design and real-world performance understanding, showcasing how scheduling decisions impact overall system efficiency.
