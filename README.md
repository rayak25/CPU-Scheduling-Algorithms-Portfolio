# CPU Scheduling Visualizer (FCFS)

An interactive web-based project that demonstrates the **First Come First Serve (FCFS) CPU scheduling algorithm**.  
Developed as part of the Operating Systems coursework, this tool helps students and developers visualize how CPU time is allocated to processes in a simple, interactive way.

---

## Features

- Simulation of the **FCFS scheduling algorithm**
- Dynamic input panel – enter process details such as arrival time and burst time
- Automatic calculation of:
  - Waiting Time
  - Turnaround Time
  - Average CPU Utilization
- Interactive Gantt chart for real-time visualization
- Educational focus – ideal for learning OS scheduling concepts

---

## Tech Stack

| Layer | Technology Used |
|-------|------------------|
| Frontend | HTML, CSS, JavaScript |
| Visualization | Canvas / Chart.js |

---

## How It Works

1. Enter process details (arrival time and burst time) for each process
2. Click "Run Simulation"
3. The tool generates:
   - Gantt Chart  
   - Waiting Time and Turnaround Time table  
   - Performance summary  

This visualization shows how CPU time is allocated to processes in **FCFS order**.

---

## Learning Objectives

- Understand how the FCFS scheduling algorithm works
- Learn to calculate waiting time and turnaround time
- Visualize process scheduling with an interactive Gantt chart
